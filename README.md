# .github

This repository stores GitHub-wide configuration and shared community files for the `alikrik` account.

## Purpose

Use this repository to keep default files that GitHub can apply across other repositories when the same files are not defined locally.

Typical contents include:

- issue templates
- pull request templates
- discussion templates
- contribution and support guidance
- other shared community health files

## How it works

Files added here can be used as account-level defaults for repositories owned by `alikrik`, helping keep standards and contributor guidance consistent across projects.

Repository-specific files still take precedence when they exist in an individual repository.
